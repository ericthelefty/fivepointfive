# Blanket
**Type:** Gear
**Cost:** 5 SP
**Weight:** 3 lb.
**Source:** SRD 5.2.1, p. 96

While wrapped in a blanket, you have Advantage on saving throws against extreme cold (see “Gameplay Toolbox”).

## Effects
```yaml
- advantage: { roll: save:all, scope: { against: { hazard: extreme-cold } }, when: { player: "Wrapped in the blanket" } }
```
